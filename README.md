# Decoraci-n-al-estilo-de-fines-del-siglo-XVIII
A fines del siglo XVIII, y bajo la influencia de los estilos Luis XVI y Directorio, se impone la severidad del neoclásico, produciéndose entonces algunos muebles de notable belleza: sofás con asientos de rejilla, canapés de caoba, escribanías lacadas, burós y librerías, cómodas, etc., que demuestran la despersonalización del mueble español, el cual deja de ser tal para convertirse en un mueble al gusto imperante en Europa. Ello es debido a la sugestión de las formas francesas e inglesas, que en este tiempo alcanzan su máximo esplendor.
